# Pilot message drafts

These are drafts only. Sending them is outside this repository task.

## English invitation

I’m looking for five volunteers to try a small prompt-cache audit on one real
LLM task. It can inspect prompt/request construction and configuration, or a
normalized routing export if you already have one. The goal is an honest
finding, a justified no-change result, or a concrete next measurement; no
performance claim is expected.

The Python helpers run locally without network access; an agent-led audit uses
your configured agent's data-processing settings. The pilot operator does not
need secrets, customer data, full private repositories, raw prompts or logs. Optional
feedback is just the outcome, approximate time, help needed, and one useful or
confusing point. Would you like to take part?

## English follow-up

Thanks for trying the audit. If you are comfortable sharing a small summary,
please send the audit path, outcome, approximate time to first result, help
needed, and one useful or confusing point. A redacted excerpt is optional; no
source repository or raw log is needed.

If a similar real task comes up later and you choose to use the skill again
without live help, please mention that at the next check-in. There is no need
to create a task just to repeat the pilot.

## Приглашение на русском

Ищу пять добровольцев для небольшого аудита промпт-кэша на одной реальной
задаче с LLM. Можно проверить сборку промпта и запроса вместе с конфигурацией
или разобрать нормализованный экспорт маршрутизации, если он уже есть. Хороший
результат — обоснованная находка, вывод «ничего менять не нужно» или конкретное
следующее измерение. Доказывать рост производительности не требуется.

Python-скрипты работают локально без сети; аудит с агентом использует настройки
обработки данных вашего агента. Мне не нужны секреты, данные клиентов, приватный
репозиторий, исходные промпты или полные логи. Для обратной
связи достаточно указать результат, примерное время, понадобившуюся помощь
и один полезный или непонятный момент. Хотите поучаствовать?

## Сообщение после аудита на русском

Спасибо за участие. Если удобно, пришлите короткое резюме: какой путь аудита
вы выбрали, какой получился результат, сколько времени потребовалось до первого
результата, какая помощь понадобилась и что оказалось полезным или непонятным. Небольшой
обезличенный фрагмент можно приложить по желанию; код проекта и исходные логи
не нужны.

Если позже появится похожая реальная задача и вы сами снова запустите скилл без
помощи в процессе, расскажите об этом при следующем контакте. Специально
придумывать задачу ради повтора не нужно.
