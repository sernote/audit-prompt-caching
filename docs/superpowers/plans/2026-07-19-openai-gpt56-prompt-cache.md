# Minimal GPT-5.6 prompt-cache implementation plan

Date: 2026-07-20

This plan replaces the earlier exhaustive implementation plan. It deliberately
keeps the skill an audit toolkit rather than a provider cache simulator.

## 1. Request linting

Files:

- `audit-prompt-caching/scripts/layout_linter.py`
- `audit-prompt-caching/references/rules.json`
- `tests/test_prompt_cache_scripts.py`

Add compact GPT-5.6 detection, request-wide policy validation, marker placement
validation, AP-11 findings, and a small `cache_policy` result. Do not turn the
four-write budget into a marker-count validity rule.

Tests: valid implicit/explicit requests, invalid mode/TTL/marker, wrapper
conservatism, malformed input.

Commit: `feat: lint GPT-5.6 cache controls`.

## 2. Usage accounting

Files:

- `audit-prompt-caching/scripts/analyze_usage_logs.py`
- two small GPT-5.6 usage fixtures
- expected usage summary
- tests

Add exact OpenAI Responses/Chat extraction, inclusive write accounting,
Anthropic/Bedrock additive accounting, ambiguous wrapper mode, explicit
accounting override, normalized write fields, and warnings.

Tests: one focused case per accounting mode, OpenAI denominator, warning, and
normalized JSONL.

Commit: `feat: account for prompt cache writes`.

## 3. ROI

Files:

- `audit-prompt-caching/scripts/estimate_cache_roi.py`
- tests

Add write rate and price, finite/range validation, mutually exclusive token
shares, component costs, schema metadata, and negative savings.

Tests: standard paid-write case, zero-write compatibility, invalid arguments,
boundary rates, negative outcome.

Commit: `feat: price prompt cache writes`.

## 4. Reporting

Files:

- `audit-prompt-caching/scripts/render_audit_report.py`
- expected Markdown report
- tests

Render usage warnings and read/write evidence. Add optional estimator ROI JSON
with compact provenance/type/finite validation and cost assessment. Unpriced
reports must not claim savings.

Tests: unpriced JSON, warning Markdown, valid ROI, malformed/tampered ROI,
legacy golden.

Commit: `feat: report prompt cache writes`.

## 5. Skill and reference

Files:

- `audit-prompt-caching/references/openai.md`
- `audit-prompt-caching/SKILL.md`
- behavior and trigger eval files

Document the verified GPT-5.6 controls, paid writes, data-control caveats,
script routing, and the limitation that prefix comparison is whole-input rather
than a provider breakpoint simulator.

Commit: `docs: update OpenAI prompt cache guidance`.

## 6. Verification and delivery

Run:

```bash
python3 -m unittest tests/test_prompt_cache_scripts.py
python3 audit-prompt-caching/scripts/validate_skill_package.py audit-prompt-caching
python3 audit-prompt-caching/scripts/run_trigger_eval.py audit-prompt-caching
git diff --check
```

Compile all scripts/tests, remove generated bytecode, run one held-out GPT-5.6
audit scenario, review the final diff for scope, then push and open a PR.
